Argus is an on-chain mandate for AI agents trading on Injective. An agent can place orders for you. It cannot decide what it is allowed to do.

The owner signs the limits once, offline. ArgusMandate re-derives the reference price from Injective's oracle precompile and refuses anything outside those limits before the order reaches the exchange module.

Reproduce a refusal yourself

Every refusal is a typed revert, so anyone can replay one. No key, no indexer, no server.

cast call 0x777B7A41F36eCd8703cC09C2cfd42de4Bd90Dc83 \
  --data $(cast tx 0xd1a2bd13…c06f3b input --rpc-url $INJ) \
  --from 0x1558D690F5408e8D29241E8a260a2D9b75f6f3a6 \
  --block 145998350 --rpc-url $INJ

execution reverted, data: 0xe3a504e8
  …03e8   deviation = 1000 bps
  …0064   band      =  100 bps

0xe3a504e8 is OutsideBand(uint256,uint256). The agent asked to trade 10% away from the oracle; the owner had signed 1%.

The mandate

The owner signs one EIP-712 TradingMandate, offline, and never needs gas again.

marketIdthe only market that can be traded
oracle triple + encodingthe only price source that counts
allowedSideslong-only, short-only, or both
priceBandBpshow far from the oracle an order may be priced
maxOracleAgehow stale the price may be before trading stops
maxOrderNotionalthe largest single order
maxTotalNotionalthe most this mandate can ever trade
cooldownminimum seconds between orders
agentwho may relay — zero means anyone
nonce, deadlinerevocable any time, expires on its own

A stolen agent key, a hallucinated price or a prompt-injected instruction cannot trade a market the owner did not name, breach the caps, price outside the band, or execute at all while the oracle is stale.

Why this needs Injective

The oracle precompile

Lets the contract re-derive the reference price in the same transaction as the order, with a timestamp. The agent cannot sit between the mandate and its price source.

The exchange precompile

The order goes straight to Injective's native central limit order book from Solidity. No AMM, no router, no bridge.

Where RWA already trades

135 RWA markets, nearly half of all markets on the chain. Agents trading those need mandates before institutions let them near a position.

Status

Deployed and working on Injective EVM testnet. 43 tests pass from a clean clone; every refusal path above is live and reproducible on-chain today.

One step remains for a filled order: the contract's exchange subaccount holds no USDC margin, and the testnet BTC book currently has no asks, so an accepted order is handed to the exchange module and declined there — by the market, not by Argus. The demo prints that distinction rather than hiding it.

Argus began on Mantle as a non-custodial risk agent for tokenized equities, where it won Best in Track (AI × RWA) at the Mantle Turing Test. This is the same guarantee pointed at a new counterparty: the party that proposes a trade is never the party that authorises it.
